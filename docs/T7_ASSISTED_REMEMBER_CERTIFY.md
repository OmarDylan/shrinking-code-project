## Install and run

Unzip the patch in the existing `shrinking-code-project` directory. The patch writes only `src/t7_assisted/`, `docs/T7_ASSISTED_REMEMBER_CERTIFY.md` and `scripts/check_t7_first_two.py`. It does **not** replace `src/t7/main.py`, `src/t7_human/main.py`, any frozen tests, or T1–T6 data.

**Review all three Python files before executing them.** To run only the two frozen V2 checkers:

```bash
python3 scripts/check_t7_first_two.py
```

That wrapper runs `tests/check_remember.py` and `tests/check_certify.py` against `src/t7_assisted/main.py` using the repository's current `data/splits/seed1/` files. A result of `PASS` applies only to that competency test, not all of T7.

If you instead implement unaided T7 independently, keep your work in `src/t7_human/main.py` and do not copy the AI-assisted adapter into it while describing that code as human-only.
