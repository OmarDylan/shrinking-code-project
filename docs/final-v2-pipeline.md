# Final V2 batch (T1–T6)

Run from the existing main branch on the authenticated Mac using the command in the accompanying instructions. Do not run another generation batch in parallel. r02 is retained; r03–r11 are nine fresh independent generation repetitions. An already recorded result is never regenerated. All six treatments retain the frozen contract, model, and failure policy. The budget guard uses accumulated API-equivalent costs for r03–r11 and conservatively reserves the nominal $0.50 cap per upcoming call; it is not a guaranteed hard spending limit and does not represent subscription charges. An unresolved infrastructure failure requires inspection; recorded syntax failures and blocked outcomes are not retried. Local generation requires an awake Mac and quota. There is a single source-review checkpoint before remote execution; review all snapshots and raw records before approval. The cloud evaluates in restricted, network-disabled containers with read-only input mounts, no passed credentials, and a writable result mount. This is defense in depth, not a hardened oracle or a guarantee that generated code is safe. Do not execute unreviewed generated programs locally. All r02–r11 evaluation runs use the same dependency pins from r02 (see Dockerfile); the Python 3.13 base image and hardware may vary. Environment manifests are included. All evaluations are rerun in that configuration; no r02 regeneration.

Each repetition yields 60 planned outcomes. Snapshot hashes and metrics are kept with the source. The aggregate script rejects missing, duplicate or unresolved records. The independent unit is one full treatment sequence per repetition, not a skill, row, or Race episode. `same()` and `ranks()` follow https://txt.github.io/seai26f/gloss6.html with thresholds .35, .195, 1.36 and upper median; rank 0 is a metric-specific tier, not an overall winner. A minimum of five observations is an explicit analysis convention. Results conditional on complete or passing source are separate from unconditional competency and attempted-call resources. r02 is a validation run; include sensitivity excluding it. No V1 pooling. T7 must be genuine independent manual prudence work; a single manual reference is descriptive only. EZR tuning requires a separately designed experiment and must not alter or be pooled with these frozen V2 results. Do not invent either result. The report is an analysis of the automated treatments, not a complete seven-treatment final report. The estimated cost budget defaults to $50 for r03–r11; set it yourself if appropriate.
