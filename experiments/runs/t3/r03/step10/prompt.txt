Earlier skill remember specification (documentation):
Remember

Requirements 1–2. Read fully observed train and test CSVs. Compute each goal's
training mean and sample SD (n-1 denominator), then normalize the value v:
`z = clamp((v - mean) / (sd + 1e-32), -3, 3)`;
`norm(v) = 1 / (1 + exp(-1.702 * z))`.
The heaven value h is 0 for Lbs- and 1 for Acc+, Mpg+.
`d2h = sqrt(sum((norm(v)-h)^2 for the three goals) / 3)`.
Lower is better. Use the observed complete goals for this retrospective task.
Rank by unrounded score then original index. Return all test scores in source order,
the first ten ranked indices, and the best, upper-middle (rank len(test)//2), worst.

Command: `python3 main.py remember --train TRAIN --test TEST`
Output: `{ "scores": [number,...], "top": [index,...], "best": index, "median": index, "worst": index }`.
The numerical evaluator uses absolute error <1e-7.

Earlier skill certify specification (documentation):
Certify

Requirements 5–6. Compare supplied numeric distributions, each containing >=2 values.
Let n=len(xs), m=len(ys). Use sample variances vx, vy (n-1, m-1 denominators).
Pooled variance = ((n-1)*vx + (m-1)*vy)/(n+m-2).
Cohen = abs(mean(xs)-mean(ys))/(sqrt(pooled variance)+1e-32).
For constant samples the denominator convention is still 1e-32, even when the
means differ. Do not replace this with another finite sentinel or infinity.
Cliffs = abs(sum(sign(x-y) over every x in xs and y in ys))/(n*m); ties count 0.
KS = max_v |count(xs<=v)/n - count(ys<=v)/m| / sqrt(1/n+1/m), evaluated
at every distinct observed value in the union; include all ties at that value.
Same is true exactly when Cohen <=0.35 AND Cliffs <=0.197 AND KS <=1.36.
These thresholds preserve the r01 evaluator; rather than change them post hoc, any
separate cross-treatment statistical method will be explicitly labeled.

Command: `python3 main.py certify --train TRAIN --test CASES_JSON`
Input: `[{"xs":[number,...],"ys":[number,...]},...]`.
Output: `{"comparisons":[{"cohen":number,"cliffs":number,"ks":number,"same":boolean},...]}`.
One comparison per case, in supplied order. Numeric comparison tolerances are 1e-9
relative and absolute. No model training is necessary.

Earlier skill blame specification (documentation):
Blame

Requirements 9–10. Use fully observed goals; association is not causation.
Use Remember's normalization for goals AND for each numeric input (that input's
training mean/sample SD). Sort training indices by (round(d2h,12), index).
Let q=max(1,len(train)//4); good=first q training cars, poor=last q.
A numeric profile center is norm(mean of that group's raw nonmissing values),
using the full training column's normalization, NOT mean of normalized values.
For observed input x, numeric evidence = max(0, abs(norm(x)-good_center)
- abs(norm(x)-poor_center)). Categorical evidence = max(0, poor frequency minus
good frequency for that row's category); each frequency divides by the nonmissing
count in its own group (zero if no known values). Missing input evidence = 0.
Goal gap = abs(norm(observed goal)-heaven). Include all four feature names and
all three goal names. For BOTH order lists, sort names by (-round(score,10), name).
Scores in [0,1], compare numerically with absolute tolerance 1e-9 (and usual relative tolerance).

Command: `python3 main.py blame --train TRAIN --test TEST`
Output: `{"diagnoses":[{"goals":{goal:number,...},"features":{feature:number,...},"goal_order":[name,...],"feature_order":[name,...]},...]}`.
One diagnosis per test row in input order.

Earlier skill justify specification (documentation):
Justify

Requirements 11–12. For row j compare with k=(j+1)%len(test). Use observed goals,
Remember scores and Blame's diagnostic method. Sort training d2h values and use
upper-middle value at index len(train)//2 (not the average of two middle values).
Accepted iff round(score,12)<=round(cutoff,12). Winner is null if the two scores
match rounded to 12 places; otherwise index of the lower unrounded score.
If a winner exists, each goal's advantage = loser's squared goal gap minus winner's
squared goal gap. Rank by (-round(advantage,10), goal name); choose first.
Otherwise advantage_goal=null. Weakest_goal = first of current row's goal_order.
Top_feature = first of current row's feature_order only when its evidence >1e-10;
otherwise null. Explanations are retrospective, not causal claims.
The human-readable text must contain the case-sensitive phrase `Car J accepted`
or `Car J rejected` (J replaced with index), the score, other score, and cutoff
formatted with three digits after the decimal point; include weakest_goal. When a
winner exists, include `Recommend car W` (W replaced with index) and advantage_goal;
otherwise include the word `tie`. If top_feature is not null, include that name.
Additional prose is permitted.

Command: `python3 main.py justify --train TRAIN --test TEST`
Output: `{"explanations":[{"row":index,"other":index,"score":number,"other_score":number,"cutoff":number,"accepted":boolean,"winner":index_or_null,"advantage_goal":name_or_null,"weakest_goal":name,"top_feature":name_or_null,"text":string},...]}`.

Earlier skill fix specification (documentation):
Fix

Requirements 15–16. Test goals are masked; all four input features are available.
This skill requires a common prediction model even if Guess chose a different one.
Use Remember's normalization for all three numeric input columns. Distance between
rows = sqrt(mean of four squared feature gaps): numeric gap = normalized value A
minus normalized value B, categorical origin gap = 0 if same else 1.
For any input row, sort all training indices by (round(distance,12), index).
Predict d2h as the arithmetic mean of the five nearest training rows' observed
Remember scores. Calculate cutoff as sorted training d2h[len(train)//2].
Rank training rows by (round(d2h,12), index); good = first max(1,len(train)//4).
Candidate menu: scan good in that order, keep the first 12 DISTINCT (Clndrs, Volume)
pairs as numeric values. Only those two input fields may change; all other inputs
remain fixed. For each test row, before = prediction. If round(before,10) <=
round(cutoff,10), return unchanged with status already_good. Otherwise consider
all menu pairs, skipping pairs that change neither value. Recompute prediction
after editing, and retain candidates where round(before-after,10)>=0.05.
Choose minimum tuple (number of changed values, round(distance(original,edited),10),
round(after,10), (new_Clndrs,new_Volume)). Return only changed fields with numeric
values, before and after as scalar numbers, and status improved. If no candidate
qualifies, return unchanged with status no_candidate. For unchanged rows use
empty changes and after=before. Report estimated improvements, not causal effects.

Command: `python3 main.py fix --train TRAIN --test MASKED_TEST`
Output: `{"repairs":[{"row":index,"before":number,"after":number,"changes":{feature:number,...},"status":"already_good|improved|no_candidate"},...]}`.
Use exactly one of the three status strings; rows in original order.
